# 피다 (P의 다이어리)

폰에 귀속되는 개인 자기관리 앱. 어설픈 완벽주의자 P가 꽃피는 하루를 쌓아가는 곳.
모든 데이터는 브라우저(localStorage)에만 저장됩니다.

## 주요 기능

- **취침·기상 streak** — 자정 전 취침 인정, 새벽 5시 이후 기상 인정. 주중 어기면 끊김, 주말은 보호. 취침은 아침에 어젯밤 시각을 입력 가능. 새벽(0~5시) 체크는 자동으로 어제 기록으로 들어감.
- **매일 쌓기** — 독서(하루 여러 번 카운트, 매일), 경제 공부(매일, 주말 streak 보호), 운동(주 3회 목표, AOKC 앱 연동 링크). 연속일수·주간·월간·연간·누적 통계와 28일 잔디밭, 누적일수 레벨 뱃지.
- **오늘의 집중** — 요일제 깊은 일 (영어·코프볼 공부·논문).
- **오늘 더 할 일** — 하루 최대 3개.
- **저녁 5분** — 한 줄 기록 + 기분 + 돈(지출/수입, 월 자유 용돈 5만원 봉투 게이지).
- **회수 카드** — 어제/지난주의 한 줄이 다음 날 맨 위로 돌아옴.
- **이번 주 패턴** — 취침·기상 7일 그래프(목표선), 루틴 실행 시간대 히트맵(골든타임 띠).
- **백업·복원** — 텍스트 복사 또는 파일로 백업, 붙여넣기/파일로 복원.

## 설정 바꾸기 (index.html 상단 script)

- `DAILY_ROUTINES` : 매일 쌓기 루틴, 운동 주 목표 횟수, weekendProtect(주말 보호)
- `DEEP_SCHEDULE` : 요일별 집중 과제
- `BED_LATEST` / `WAKE_EARLIEST` : 취침 마지노선(기본 자정) / 기상 하한(기본 5시)
- `AOKC_URL` : 운동 카드의 AOKC 앱 링크
- `LEVELS` : 누적일수 레벨 단계
- `MONTHLY_FREE` : 한 달 자유 용돈 한도

## GitHub Pages 배포

1. 저장소(Public)에 이 폴더의 파일 전부 업로드
2. Settings → Pages → Source: Deploy from a branch, Branch: main / (root)
3. `https://<아이디>.github.io/<저장소이름>/` 접속

## 폰 홈 화면에 추가 (iPhone)

Safari로 접속 → 공유 → 홈 화면에 추가. 황금 꽃(P) 아이콘으로 추가됨.

## 주의

- 데이터는 사이트 주소별 브라우저 저장소에만 있음. 주소가 바뀌면 기록이 안 보임.
- Safari 방문기록/캐시 완전 삭제 시 기록도 삭제됨. **백업 기능을 주기적으로 사용할 것.**
- 아이콘/이름 변경 후 홈 화면 재추가 시, 데이터가 비어 보이면 백업·복원 메뉴로 복원.
